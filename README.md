# Dance of Dragons

A Telegram strategy role-playing game inspired by the world of Westeros.

## Project Overview

Dance of Dragons is a multiplayer strategy game featuring noble houses, dragons, armies, diplomacy, economy, castles, and seasonal events.

## Main Systems

- Telegram Bot
- Telegram Mini App
- Admin Dashboard
- Player Dashboard
- House and Character Management
- Dragon Management
- Army and Battle Management
- Economy and Buildings
- Diplomacy and Trade
- World Map
- Seasonal Themes
- In-game Messaging
- Missions and Events

## Technology

- Frontend: HTML, CSS, JavaScript
- Backend: Python
- Database: PostgreSQL

## Game Calendar

- One real day equals one in-game year.
- Each season lasts two real days.
- Character and dragon ages advance once per real day.

## Security

Bot credentials and database passwords must be stored securely as environment variables. Never commit secrets to GitHub.
